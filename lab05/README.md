# ЛР №5 — каталог товаров с фильтрами

**Цель:** страница «Каталог товаров»: загрузка через `fetch`, фильтры (категория и диапазон
цены), фильтрация на клиенте, состояния загрузки и ошибки, отмена запроса при
размонтировании (`AbortController`).

Данные берутся с публичного API https://fakestoreapi.com/products (нужен интернет).

## Запуск

Команды выполняются из папки `lab05/`:

```
npm install
npm run dev
```

Откроется http://127.0.0.1:5173/

Проверка сборки и линтера:

```
npm run build
npm run lint
```

## Структура

```
src/
├── main.jsx
├── App.jsx                     заголовок и <ProductList />
└── components/
    ├── ProductList.jsx         контейнер: загрузка, состояния, фильтрация
    ├── ProductCard.jsx         карточка товара (только отображение)
    └── Filters.jsx             форма фильтров с валидацией
```

## Что сделано

- `ProductList`: первый `useEffect` — загрузка с `AbortController` и проверкой `res.ok`;
  второй `useEffect` — пересчёт отфильтрованного списка; состояния `loading`, `error`,
  `products`, `filters`.
- `Filters`: локальные значения применяются кнопкой «Применить фильтры»; валидация —
  отрицательные цены и `«от» > «до»`; правка поля сбрасывает его ошибку.
- `ProductCard`: заглушка картинки через Data URI, название, категория, цена.

Задания для самостоятельной работы:

1. выбор нескольких категорий (массив в `useState`, чекбоксы);
2. ползунки (`range`) для минимальной и максимальной цены, связанные с числовыми полями.

Замечания: цены в API — в долларах, на слайдах они выводятся с «₽», оставлено как в задании.
Строка `eslint-disable` у второго `useEffect` оставлена осознанно: по заданию пересчёт
выполняется в эффекте (подробнее в отчёте).
