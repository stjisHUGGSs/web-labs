# ЛР №3 — форма обратной связи (useState, валидация)

**Цель:** научиться управлять состоянием формы через `useState`, реализовать клиентскую
валидацию полей и стилизовать состояния поля: покой, фокус, ошибка, успех.

## Запуск

Команды выполняются из папки `lab03/`:

```
npm install
npm run dev
```

Откроется http://127.0.0.1:5173/

Проверка сборки и линтера:

```
npm run build
npm run lint
```

## Структура

```
src/
├── main.jsx
├── index.css
├── App.jsx                     заголовок и форма
├── App.css
└── components/
    ├── FeedbackForm.jsx        форма: состояния, валидация, обработчики
    └── FeedbackForm.css        стили формы и состояний полей
```

## Что сделано

- Поля «Имя», «Email», «Сообщение» — управляемые компоненты (`useState`).
- Состояния `errors`, `touched`, `isSubmitting`, `submitted`; ошибка показывается только
  у «тронутых» полей (после ухода из поля), дальше проверка идёт на лету.
- Валидация: имя (≥ 2 символа, буквы/пробелы/дефис), email (формат), сообщение (≥ 10 символов).
- Отправка: проверка всех полей, имитация запроса 1,5 с (`setTimeout`), экран «Спасибо за
  обращение!» со сбросом формы.
- CSS-состояния поля: покой, `:focus`, `--error`, `--valid`; динамические классы через
  `getInputClass`.

Задания для самостоятельной работы:

1. счётчик символов `N / 500`, `maxLength` и проверка верхнего лимита;
2. поле «Телефон» с маской `+7 (XXX) XXX-XX-XX` и проверкой формата (необязательное);
3. переключатель «Хочу получить ответ»: включён (по умолчанию) — Email обязателен,
   выключен — можно оставить пустым; правила обновляются сразу.
