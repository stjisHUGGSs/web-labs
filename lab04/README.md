# ЛР №4 — калькулятор скидок

**Цель:** научиться управлять состоянием формы с несколькими связанными полями через
`useState`, обрабатывать события `onChange` и `onClick`, рассчитывать цену со скидкой и НДС.

## Запуск

Команды выполняются из папки `lab04/`:

```
npm install
npm run dev
```

Откроется http://127.0.0.1:5173/

Проверка сборки и линтера:

```
npm run build
npm run lint
```

## Структура

```
src/

├── DiscountCalculator.jsx        состояние, обработчики, расчёт, разметка

```

## Как считается

```
скидка             = цена × процент / 100
цена после скидки  = цена − скидка
НДС (22%)          = цена после скидки × 0,22
итого              = цена после скидки + НДС
```

Скидки по категориям: электроника 5%, одежда 15%, продукты 10%, книги 20%, другое 0%.
Результат показывается только после нажатия «Рассчитать»; любое изменение данных его скрывает.

## Что сделано

- Ввод цены (строка, только цифры и точка), выбор категории, кнопки «Рассчитать» и «Сбросить».
- Валидация цены (пусто / не число / не больше нуля), таблица промежуточных вычислений.

Задания для самостоятельной работы:

1. несколько товаров — у каждого цена и категория, итог — сумма по позициям;
2. промокод `WELCOME10` — ещё 10% скидки поверх основной;
3. ползунок ручной скидки 0–50%, заменяет скидку категории;
4. переключатель «с НДС / без НДС»;
5. история расчётов — последние 5 под формой.
