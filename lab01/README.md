# ЛР №1 — React + Vite

**Цель:** создать проект на Vite, структурировать его семантической разметкой и
CSS-модулями, собрать интерфейс из переиспользуемых JSX-компонентов, подключить
данные для карточек статей.

Блог-страница со списком статей. Оформление — в стиле блогов 2000-х: Verdana,
рамки, жёсткие тени.

## Запуск

Команды выполняются из папки `lab01/`:

```
npm install
npm run dev
```

Откроется http://127.0.0.1:5173/

Проверка сборки и линтера:

```
npm run build
npm run lint
```

## Структура

```
src/
├── main.jsx                  точка входа
├── App.jsx                   сборка страницы
├── App.module.css
├── index.css                 базовый сброс и фон страницы
├── data/
│   └── articles.js           массив из 8 статей
└── components/
    ├── Header/               шапка сайта со счётчиком статей
    ├── Nav/                  навигация
    ├── ArticleCard/          карточка одной статьи
    └── ArticleList/          сетка карточек (flexbox, 4 в ряд)
```

Каждый компонент лежит в своей папке вместе со своим `*.module.css` —
классы изолированы, имена не конфликтуют между компонентами.

## Что сделано

- Проект на Vite + React (JavaScript), шаблон очищен от демо-кода
- Семантические теги: `header`, `nav`, `main`, `section`, `article`, `footer`, `time`
- Данные карточек — в `src/data/articles.js`, список рендерится через `.map()`
  с `key`, количество карточек задаётся только длиной массива
- Сетка карточек на flexbox, адаптивная: 4 → 3 → 2 → 1 колонка
- Задания для самопроверки: 7-я и 8-я карточки, 4 карточки в ряд, навигация
  вынесена в `Nav`, счётчик статей в шапке
